# Monthly Scientific Audits

This directory contains the curated scientific layer for UnPeeragogy's public monthly log.

One file per month:

`YYYY-MM.md`

The file may be prepared by one or more research agents, but every assertion must remain traceable to repository artefacts, external sources, or explicitly labelled interpretation.

The monthly log generator appends the file verbatim after the automatically generated activity/metrics sections.

See `docs/AGENT_SCIENTIFIC_AUDIT.md`.
