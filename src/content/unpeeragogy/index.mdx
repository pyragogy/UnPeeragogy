"List the patterns by title; give them a unique number; assign them to categories." A tool for organizing patterns. A reference system.

**Why it matters:** An index serves as memory for the group. It says "these are our patterns." It gives the illusion of order. But an index doesn't tell you which patterns are active, which are abandoned, which are aspirational. An index tells you what exists. Not what works.

The Handbook's index is a map. Beautiful, organized, complete. But maps don't say which territories are safe and which are dangerous. They say: "here is something." They don't say "this pattern failed three times." The index is the place where failures don't exist because they've been removed.

**What to do instead:** An index needs metadata. Not just "what pattern." Also "what condition." Active, tested, discarded, aspirational. An index of living patterns is different from an index of dead patterns. The Handbook's index makes all patterns look alive. That's dishonest.

> **Perturbator:** *"Your index has 40 patterns. How many are active? No idea, right? Because the index doesn't say. It lists everything. Alive and dead. Patterns that work and patterns that were written and never tested. An index without status is a cemetery that calls itself a garden."*
