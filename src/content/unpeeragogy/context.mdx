"When you write about peeragogy, you need to consider the context." "Patterns are not universal."

The Handbook admits that context matters. Then it writes patterns as if context were optional.

**Why it matters:** Context is the variable that breaks all patterns. A pattern works in a small, motivated, co-located group. It fails in a large, distributed, low-commitment group. The pattern is the same. The context is different. And the difference determines everything.

The Handbook acknowledges context in the introduction. Then proceeds to present patterns without systematic context notation. It doesn't say: "this pattern works if the group has 5-15 members and meets weekly." It says: "this pattern helps groups coordinate." The first is honest. The second is aspirational.

**What to do instead:** Every pattern should include context prerequisites. "This pattern requires: trust among members, at least 3 months of shared history, and a minimum of 2 hours per week per participant." If the prerequisites aren't met, the pattern may not work. This would make the Handbook less confident. Also more useful.

> **Perturbator:** *"Context is everything. The Handbook says it, then ignores it. Patterns are presented as universal. They're not. They're specific to the group that wrote them. A pattern that works for a PhD student in 2012 may not work for a factory worker in 2025. The Handbook doesn't tell you this. You have to guess. Guessing is expensive."*

**Reference:** Peeragogy Handbook, "Context" section.
