## Summary

Comprehensive guides kill participation. Theory says documentation helps newcomers navigate complexity — practice shows that expert-authored guides become gatekeeping mechanisms. The cognitive load mismatch between veteran knowledge and newcomer capacity turns orientation into exclusion.

## Euristiche Operative

### Positive Rule

> This pattern works when guides are tested with actual newcomers and revised based on their feedback. While no confirming evidence was identified in this synthesis, the pattern succeeds when guide complexity matches newcomer capacity, not veteran knowledge scope.

### Negative Rule

> Do not assume comprehensive guides increase participation. Wikidata governance documentation shows that complex processes create barriers that entrench existing contributors and exclude newcomers, turning guides into gatekeeping mechanisms.

## Sintesi Obliqua

The pattern claims that creating guides alongside learning produces better navigation tools for newcomers. Partial verification — but only when guides match newcomer capacity, not expert scope. Wikidata's governance documentation and Drupal's community working groups both demonstrate how comprehensive processes entrench existing contributors while systematically excluding newcomers through complexity barriers. The real mechanism isn't about guide creation as learning — it's about cognitive load distribution and who controls the documentation process. Guides work when they forget what experts know.
