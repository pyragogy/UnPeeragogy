## Summary

Self-organization needs someone to organize first. Theory promises emergent structure from peer interaction — practice shows you need facilitators, dispute mechanisms, and institutional backing. Without scaffolding, peer learning collapses into enthusiasm without persistence.

## Evidenze Grounded

### 🔹 Confirming (2)

**Caso 1 — P2PU learning circles sustainability**
- **Fenomeno:** Peer learning models with defined facilitator roles and institutional partnerships are more sustainable than purely peer-driven learning.
- **Fonte:** [https://www.p2pu.org/en/learning-circles/](https://www.p2pu.org/en/learning-circles/)

**Caso 2 — OpenStreetMap Data Working Group resolution**
- **Fenomeno:** Formal dispute resolution bodies with binding authority and published reasoning resolve peer production conflicts that informal consensus cannot.
- **Fonte:** [https://wiki.osmfoundation.org/wiki/Data_Working_Group](https://wiki.osmfoundation.org/wiki/Data_Working_Group)

### 🔸 Complicating (2)

**Caso 1 — WebAssembly Community Group governance**
- **Fenomeno:** Choosing lighter governance models for standards development trades authority for speed, creating different failure modes for peer participation.
- **Fonte:** [https://www.w3.org/community/webassembly/](https://www.w3.org/community/webassembly/)

**Caso 2 — IETF working group rough consensus**
- **Fenomeno:** Rough consensus governance only works when backed by hierarchical escalation paths; pure consensus without appeals fails.
- **Fonte:** [https://www.ietf.org/about/](https://www.ietf.org/about/)

## Euristiche Operative

### Positive Rule

> This pattern works when institutional scaffolding supports peer exploration. P2PU learning circles show that defined facilitator roles and institutional partnerships create sustainable peer learning environments that outlast purely peer-driven initiatives.

### Negative Rule

> Do not implement SOLE without facilitator roles and escalation mechanisms. The IETF rough consensus model shows that pure consensus without appeals fails, and OpenStreetMap demonstrates that informal consensus cannot resolve conflicts that require binding authority.

## Sintesi Obliqua

The pattern claims peer interaction generates sustainable learning structures through reciprocal mentoring and emergent organization. Partial verification — but only when institutional scaffolding exists. P2PU learning circles work because they have defined facilitator roles and library partnerships, while OpenStreetMap's Data Working Group resolves conflicts that informal consensus cannot handle. WebAssembly's lighter governance complicates this by showing minimal structure can work, but the missing piece is duration analysis. Most evidence captures early-stage enthusiasm, not what survives after the founding energy dissipates.
