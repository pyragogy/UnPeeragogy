"This section collects patterns and resources related to technologies, services, and platforms." The menu of tools.

**Why it matters:** The technology section is a list of tools. Some used, some recommended, some discussed. It's a catalog. Catalogs are useful for shopping. Not for solving problems.

The problem with technology sections in handbooks is that they age. Tools change. Platforms disappear. The Handbook's technology section has patterns (social bookmarking) that no longer exist. Others (real-time) describe problems that have been solved differently. The technology section is the most dated part of the Handbook.

**What to do instead:** If you discuss technology, describe principles. Not platforms. "Use a tool that allows asynchronous participation." Not "use Discourse." The principle survives. The platform dies. The Handbook has too many platforms, not enough principles.

> **Perturbator:** *"The technology section is a list of tools. Some exist. Some don't. Some are useful. Some aren't. But the real issue is: does the group need better tools or better practices? Usually, the practices are the bottleneck. Tools are an excuse. 'We need a better platform.' No. You need to use the platform you have better."*
