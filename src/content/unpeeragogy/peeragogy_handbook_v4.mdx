"Peeragogy Handbook V4." "In which we review and update the patterns."

The Handbook's fourth version. A document that talks about itself.

**Why it matters:** Writing version 4 of a handbook means the first three versions didn't complete the work. Each version is a promise of completion. Each version is also an admission of incompleteness.

The Handbook's history is one of expansion, not refinement. Each version adds patterns, sections, appendices. None simplifies. None concludes. The Handbook grows like a city without an urban plan. New buildings added without demolishing old ones. The result is a sprawling structure where it's hard to find what you need. V4 doesn't solve this. It adds more.

**What to do instead:** Version 4 should be a simplification. Remove patterns that don't work. Merge similar ones. Write case studies. A handbook isn't better because it's longer. It's better because it's more useful. V4 could be the version that actually helps groups work. But it seems to have chosen to be the version that adds more theory. A missed opportunity.

> **Perturbator:** *"Version 4. More patterns. More sections. More text. When does the Handbook stop growing and start cutting? When does it admit that not all patterns are useful? That some should be removed? The Handbook's growth is a sign of life. Also a sign of indecision. What is being added and what can't be removed?"*
