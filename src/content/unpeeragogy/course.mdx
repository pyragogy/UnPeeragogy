## Summary

Courses fail when they try to teach peeragogy directly. Theory says peer learning emerges from collaboration — practice shows it needs scaffolding first. The mechanism works backward: structure enables the freedom that creates the learning.

## Evidenze Grounded

### 🔹 Confirming (2)

**Caso 1 — P2PU learning circles sustainability**
- **Fenomeno:** Peer learning models with defined facilitator roles and institutional partnerships are more sustainable than purely peer-driven learning.
- **Fonte:** [https://www.p2pu.org/en/learning-circles/](https://www.p2pu.org/en/learning-circles/)

- **Fonte:** [https://wiki.osmfoundation.org/wiki/Data_Working_Group](https://wiki.osmfoundation.org/wiki/Data_Working_Group)

### 🔸 Complicating (2)

- **Fenomeno:** Choosing lighter governance models for standards development trades authority for speed, creating different failure modes for peer participation.
- **Fonte:** [https://www.w3.org/community/webassembly/](https://www.w3.org/community/webassembly/)

**Caso 2 — IETF working group rough consensus**
- **Fenomeno:** Rough consensus governance only works when backed by hierarchical escalation paths; pure consensus without appeals fails.
- **Fonte:** [https://www.ietf.org/about/](https://www.ietf.org/about/)

## Euristiche Operative

### Positive Rule

> This pattern works when peer learning is combined with defined facilitator roles and institutional backing. P2PU learning circles show that structured facilitation with institutional partnerships creates sustainable peer learning that outlasts individual enthusiasm.

### Negative Rule

> Do not apply pure peer governance when courses involve contested technical decisions or resource allocation. The IETF and WebAssembly evidence shows that consensus without escalation paths fails when participants have conflicting technical or organizational interests.

## Sintesi Obliqua

The pattern claims pure peer governance creates sustainable learning communities through emergent collaboration. Partial verification — but only when institutional backing provides the container. P2PU learning circles work because facilitators handle logistics while peers handle content, and OpenStreetMap resolves disputes because formal bodies exist when consensus breaks down. WebAssembly and IETF show the opposite: lightweight governance fails when technical decisions have real stakes. The missing piece isn't about peer dynamics — it's about what happens when peers disagree about something that matters. Freedom needs an engine room.
