## Summary

Real-time democracy is just tyranny of the unemployed. Theory says synchronous tools add richness to async platforms — practice shows they create participation hierarchies based on schedule flexibility. The pattern works when real-time decisions stay provisional.

## Euristiche Operative

### Positive Rule

> This pattern works when real-time decisions are paired with formal dispute resolution mechanisms that operate asynchronously. The OpenStreetMap Data Working Group shows that binding authority with published reasoning can resolve peer production conflicts that informal real-time consensus cannot address.

### Negative Rule

> Do not rely on real-time decision-making when members have unequal time availability. The Apache Software Foundation model shows that those with more free time accumulate authority, creating a class system within the 'flat' organization that excludes time-constrained contributors.

## Sintesi Obliqua

The pattern claims real-time tools enhance peer learning by adding audio-visual richness to asynchronous platforms. Partial verification — but only when time availability is roughly equal across participants. OpenStreetMap's formal dispute resolution shows that binding authority with published reasoning resolves conflicts informal consensus cannot touch, while Apache's meritocracy demonstrates how free time becomes accumulated power within supposedly flat organizations. The mechanism missing: how to prevent schedule privilege from becoming governance privilege. Real-time works. Until Tuesday morning.
