"Practice is a section that collects patterns that can be used in practice." "A page where patterns are illustrated with concrete examples."

The Practice section of the Handbook. Patterns to use. A page dedicated to the possibility of practical application.

**Why it matters:** The Practice section is part of the Handbook. Which is a text. A text about practice is not practice. Practice happens outside the text. It happens in groups that actually try.

The Handbook's Practice section is well-written. It describes patterns clearly. It gives examples. But a description of practice is not practice. It's a promise of practice. And promises, in peeragogical groups, are often broken.

**What to do instead:** Practice isn't in the Handbook. It's in the groups that use the Handbook. The Handbook is a map. Practice is the territory. Reading the map is not traveling. Traveling is traveling. If the Handbook wants to be practical, it should include fewer patterns and more stories of application. Application stories are closer to practice than pattern descriptions.

> **Perturbator:** *"You read the Practice section. Good. Now go practice. The Handbook can't practice for you. It can describe. It can suggest. It can't do the work. The gap between reading and doing is the only gap that matters. And it's a gap that no text can bridge."*

**Reference:** Peeragogy Handbook, "Practice" section (Peeragogy in Practice).
